# PhotoPainter 众筹前展示官网

一个无构建依赖的中文静态产品官网，用真实运行界面、演示视频与六色圆屏作品展示 PhotoPainter 当前工程原型。

## 本地预览

在本目录启动任意静态文件服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 文件结构

- `index.html` — 页面内容与语义结构
- `styles.css` / `scenes.css` — 响应式视觉系统与多尺寸应用场景
- `app.js` — 移动菜单、作品画廊、FAQ 与视频交互
- `assets/` — 已脱敏的真实产品素材

素材说明：场景主视觉为概念场景展示，并非实体原型实拍；`assets/scenarios/` 中输入图和六色输出由实际运行的 PhotoPainter 现场生成。`assets/scenarios-v2/` 进一步包含独立的每日便签、每日鸡汤、真人成年女大学生输入图，以及根据源码现有 1.54 英寸方形、4.0 / 7.3 英寸矩形驱动配置转换的六色软件输出。矩形输出证明软件适配链路，不代表对应实体矩形屏已经接入并完成刷新测试；当前实体参考组合仍为 1.69 英寸圆屏。所有软件输出均非实体屏幕照片。产品界面截图和操作录屏来自实际运行版本，演示网络及配置数据已脱敏。

## 浏览器支持

面向现代 Chrome、Edge、Firefox 与 Safari。布局针对 390、900、1440 像素宽度优化，并支持 `prefers-reduced-motion`。

## 说明

本页面仅用于众筹前展示，不包含销售、付款或个人信息收集功能。产品仍处于原型开发与兼容性验证阶段；页面未声明量产、认证、价格或交付时间。
