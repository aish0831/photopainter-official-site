# PhotoPainter 众筹前展示官网

一个无构建依赖的中文静态产品官网，用真实运行界面、演示视频与六色圆屏作品展示 PhotoPainter 当前工程原型。

## 本地预览

在本目录启动任意静态文件服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 文件结构

- `index.html` — 页面内容与语义结构
- `styles.css` / `scenes.css` — 响应式视觉系统与多尺寸应用场景
- `app.js` — 移动菜单、作品画廊、FAQ 与视频交互
- `assets/` — 已脱敏的真实产品素材

素材说明：场景主视觉为概念场景展示，并非实体原型实拍；`assets/scenarios/` 中 5 组输入图和六色输出均由实际运行的 PhotoPainter 在本次官网更新中现场生成，便签图由同一实机现场写入并渲染。输入图由 AI 生成，右侧六色图为实际软件屏幕输出文件，二者都不是实体屏幕照片。产品界面截图和操作录屏来自实际运行版本，演示网络及配置数据已脱敏。

## 浏览器支持

面向现代 Chrome、Edge、Firefox 与 Safari。布局针对 390、900、1440 像素宽度优化，并支持 `prefers-reduced-motion`。

本页面仅用于众筹前展示，不包含销售、付款或个人信息收集功能。产品仍处于原型开发与兼容性验证阶段；页面未声明量产、认证、价格或交付时间。
